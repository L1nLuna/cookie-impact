# YOLO Clicker Bot

 # Возможности
 🎚️ Настройка порога уверенности (Confidence) через ползунок в реальном времени
⌨️ Глобальная остановка по нажатию ПРОБЕЛ
⚡ Запуск по ENTER
🖼️ Поддержка .pt и .onnx моделей
🧵 Работа в отдельном потоке — интерфейс не зависает

# Структура проекта
yolo_clicker/
    app.py
    README.md
    runs/detect/cookie_derector-2/weights/
        best.pt
        best.onnx

# Управление
Действие	Клавиша / Кнопка
▶ Запустить бота	Кнопка «Старт» или ENTER
⏹ Остановить бота	Кнопка «Стоп» или ПРОБЕЛ
🎚️ Изменить порог уверенности	Ползунок в окне программы
